# 4D Sound Explorer

Vierdimensionale Körper (Tesserakt, 16-Zeller, 5-Zeller, 24-Zeller, 600-Zeller, 120-Zeller, Duoprisma, Hopf-Faserung) als leuchtende Partikelwolken in Echtzeit, dazu ein Klangraum in A-Dur-Pentatonik zum Mitspielen.

- Cursor bewegen und klicken spielt Hang-Drum-Töne und kurze Figuren
- `<<<` `>>>` wechselt den Körper
- `auto play on` lässt einen Geister-Cursor selbst spielen
- `cockpit on` zeigt alle Schalter (Projektion, zweiter Körper, 3D-Schnitt, Nachleuchten, Tempo)

Eine einzige HTML-Datei, WebGL2 und Web Audio, ohne Framework und ohne Build-Schritt.

Gebaut mit Claude Opus 5.5.
